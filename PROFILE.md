# Pexafy

Semantic (meaning-based) search engine over free-license stock photography. A single request queries 9 free stock-photo libraries (Unsplash, Pexels, Pixabay, StockSnap, Picjumbo, Kaboompics, Burst, Skitterphoto, NegativeSpace; 9M+ images) and normalizes results into one JSON schema. Supports natural-language queries in 23 languages, image-to-image search, and filtering by color, orientation, license, source, photographer, and date.
