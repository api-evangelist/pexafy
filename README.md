# pexafy
Semantic (meaning-based) search engine over free-license stock photography. A single request queries 9 free stock-photo libraries (Unsplash, Pexels, Pixabay, StockSnap, Picjumbo, Kaboompics, Burst, Skitterphoto, NegativeSpace; 9M+ images) and normalizes results into one JSON schema.
